+ Ngày 1:
- Để mà triển khai dự án thì sẽ tìm hiểu về hạ tầng của dự án:
+ Ollama: Là nơi chứa những models mà mình sẽ xài
+ Qdrant: Vector Database
+ Postgres: 1 Relational Database để ghi những thông tin quan trọng lại

- Để dựng được hạ tầng thì phải xài docker 
+ Docker Image: Là bản thảo của 1 app, trong đó sẽ chứa source code, hệ điều hành sẽ chạy, thư viện, tất tần tật những thứ liên quan về app
+ Để mà app riêng của mình được đóng gói thành 1 image thì bắt buộc phải viết Docker File
+ Docker File: là nơi định nghĩa những thư viện, hệ điều hành, source code sẽ để đâu trong container
+ Docker Container: là môi trường chạy app
    - 2 cách setup: 
    Cách 1: chạy riêng từng câu lệnh CLI để mà khởi chạy container, khởi tạo được 1 container ngay tại 1 thời điểm
    Cách 2: Chạy bằng file Docker Compose - File Docker Compose chỉ là 1 file cho chạy cùng lúc nhiều containers, viết bằng định dạng file yaml'
